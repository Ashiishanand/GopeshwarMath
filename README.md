# Gopeshwar Kailash Math · V3 development build

Standalone institutional website for Gopeshwar Kailash Math, Braj · Vrindavan.

## Structure
- Home
- About
- The Ashram
- Braj Vaas
- Seva & Welfare
- Contribution
- Contact
- Brochure
- Privacy Policy
- Terms & Conditions

The obsolete Updates and Branches pages are intentionally removed from the navigation and build.

## Language
The header language control switches between the hand-written English and Hindi versions. It does not use Google Translate, so the Hindi copy is controlled and preserves the intended tone.

Open `index.html` directly or serve the folder with any static web server.
`build_site.py` regenerates the static pages and Hindi versions.
